# Workbench

Speaker-facing and personal-prep material that supports the gnn_plan reference
docs but is not part of the proposal itself. Keep these out of the top-level
folder so a reader landing in `gnn_plan/` sees the proposal first and the prep
material only when they look for it.

Files here:

- [`TALK_TRACK.md`](TALK_TRACK.md) — live-call reference with Q1/Q2 rehearsal,
  slide-4/5 talking points, the lineage back-pocket script, things to avoid
  saying, and the baby version of open questions.
- [`SENSEMAKING.md`](SENSEMAKING.md) — personal sensemaking about why the
  representation boundary matters. Support material; the canonical sendable
  answer is [`../13_primary_answer.md`](../13_primary_answer.md).
- [`REVIEW_AND_PIVOT.md`](REVIEW_AND_PIVOT.md) — captures the external slop
  critique that drove the HATCH-IoU pivot and the post-pivot reading lens.
- [`07_source_review_prompts.md`](07_source_review_prompts.md) — per-source
  paper-review prompts for the research lane.

For the proposal itself, see [`../README.md`](../README.md) and the numbered
reference docs at the top level.
