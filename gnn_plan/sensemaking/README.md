# Sensemaking Layer

This folder is for collecting, preserving, and sharpening the research/voice
before it becomes a polished plan.

The failure mode to avoid:

> normalizing away the original voice and vision until only generic ML-system
> advice remains.

The rule here is:

- keep raw claims visible
- preserve strange or high-energy phrasing when it carries real signal
- translate claims into technical commitments only after the source claim is
  named
- separate "what I would say live" from "what the system should actually do"
- keep uncertainty and open questions instead of prematurely smoothing them

## Promotion Rule

When something matures:

- implementation detail -> promote to `../02_graph_representations.md` or
  `../experiments/README.md`
- product/model direction -> promote to `../01_problem_framing.md` or
  `../03_predictive_editing.md`
- literature support -> promote to `../04_research_map.md`
- interview phrasing -> keep in this folder or `../notes/`

Do not promote a sharp claim until the note keeps both versions:

1. original voice
2. operational translation
